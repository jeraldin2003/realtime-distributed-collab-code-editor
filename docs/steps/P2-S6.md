# P2-S6 — Presence per file

**Depends on:** P2-S5
**Goal:** The sidebar shows who is in which file.

## Build
1. On the index provider's awareness, add `activeFileId` alongside `user`. Update it whenever the active file changes (and clear it when none).
2. `FileList` shows small colored dots (up to 3, then `+N`) next to files that other users have open, with the user's name in a tooltip.
3. Remote cursors still appear only in the file doc a user is actually editing (per-document awareness already handles this; verify it).
4. Header user count remains the index awareness count.

## Files (expected)
`frontend/src/collab/usePresence.ts`, `frontend/src/components/FileList.tsx`

## Acceptance
- Three tabs on different files: each file row shows the right dots; switching files updates dots within a second or two.
- Cursors don't appear in a file the viewer isn't looking at the same doc for.
- Closing a tab removes its dot after the awareness timeout.

## Do NOT
Follow mode, chat, per-user panels, anything about permissions.
