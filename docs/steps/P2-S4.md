# P2-S4 — Create file

**Depends on:** P2-S3
**Goal:** A user can create a file; everyone sees it instantly.

## Build
1. Sidebar "New file" button opens an inline input (not a browser prompt). Validate: 1–100 chars, no `/` or `\`, not empty after trim, no existing file with the same name at the same level, total files < `MAX_FILES` (50). Show inline errors.
2. Create through `createFile` logic mirrored on the frontend (do not import from backend; copy the minimal helper into `frontend/src/collab/fileIndex.ts` and add a tests file for it). Generate the id the same way.
3. After creating, select the new file automatically for the creator only.
4. Concurrent creation with the same name from two users is allowed to produce two entries (IDs differ). The list sorts by name, then id, so both are visible. Note in `DECISIONS.md`.
5. New file docs start empty.

## Files (expected)
`frontend/src/collab/fileIndex.ts` + test, `frontend/src/components/{FileList.tsx,NewFileInput.tsx}`

## Acceptance
- Creating `utils.ts` in tab A appears in tab B immediately; typing in it syncs.
- Invalid names are rejected with a visible message.
- 50-file limit is enforced.
- Frontend helper tests pass, including concurrent create merging.

## Do NOT
Rename/delete, folders, server-side validation.
