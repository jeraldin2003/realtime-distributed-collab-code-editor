# P1-S5 — Presence

**Depends on:** P1-S4
**Goal:** See other users: name, color, cursor, selection, and a live user count.

## Build
1. `frontend/src/collab/identity.ts`: generate a random friendly name (adjective + animal) and a color from a fixed palette of 8–10 readable colors. Persist in `sessionStorage` so a refresh keeps identity within a tab.
2. Set awareness `{ user: { name, color } }` once when the provider is ready.
3. Remote cursors and selections via `y-monaco`. Inject per-client CSS from awareness (name label and color); remove CSS for users who left (monaco-editor skill).
4. Header shows `N online`, derived from awareness states (the local user included).
5. Show a small list or avatars of online users' names in the header (simple, text or dots).

## Files (expected)
`frontend/src/collab/{identity.ts,usePresence.ts}`, `frontend/src/components/{Editor.tsx,Header.tsx}`, small CSS

## Acceptance
- Each tab has a distinct name and color; refresh keeps it.
- Remote cursors and selections are visible with name labels.
- User count updates when tabs open and close (closing may take a few seconds to reflect).
- No leftover cursor style for departed users.

## Verify
3 tabs: move cursors, select text, close a tab, refresh a tab.

## Do NOT
User cap or `MAX_USERS` display (that's P1-S6), accounts, custom names input.

## Commit
`P1-S5: presence with names, colors, remote cursors`
