# P1-S0 — Scaffold

**Depends on:** nothing (folders are empty)
**Goal:** Two runnable, tooled, empty projects and a git repo. No collaboration code yet.

## Build
1. `git init` at the repo root. Add a root `.gitignore` (node_modules, dist, .env, logs). Commit nothing yet beyond the scaffold.
2. `backend/`: `npm init`, TypeScript strict, `tsx` for dev, Vitest, ESLint. `src/index.ts` only logs `backend up`. `src/config.ts` exports `PORT` (env, default 1234) and `MAX_USERS` (env, default 10) only.
3. `frontend/`: create with the official Vite React + TypeScript template. Add Vitest and ESLint if the template lacks them. Replace the default demo UI with a single `<h1>Collab Editor</h1>`.
4. Both folders define these scripts: `dev`, `build`, `typecheck`, `lint`, `test`. Each `test` script must pass with at least one trivial test.
5. Add `backend/.env.example` and `frontend/.env.example` with the variables from `docs/ARCHITECTURE.md`.
6. Root `README.md`: what the project is, and how to run backend and frontend (two terminals).
7. Record exact installed dependency versions in `docs/DECISIONS.md`.

## Files (expected)
`.gitignore`, `README.md`, `backend/{package.json,tsconfig.json,eslint config,src/index.ts,src/config.ts,src/*.test.ts,.env.example}`, `frontend/{template files,.env.example}`

## Acceptance
- `npm run dev` runs in each folder; frontend shows the heading at `http://localhost:5173`.
- `typecheck`, `lint`, `test` pass in both folders.
- Git repo exists with one scaffold commit.

## Verify
Run all five scripts in both folders. Open the frontend in a browser or fetch it with curl and confirm the heading.

## Do NOT
Install Yjs, Hocuspocus, Monaco, or any UI library. Add routing, state libraries, or CSS frameworks. Create a root `package.json`.
