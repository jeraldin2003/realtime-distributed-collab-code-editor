# P1-S2 — Frontend shell

**Depends on:** P1-S1
**Goal:** The editor UI exists and works locally. No networking.

## Build
1. Install Monaco (`monaco-editor` plus `@monaco-editor/react`, or `monaco-editor` alone; pick one, record it in `DECISIONS.md`). Follow `.agents/skills/monaco-editor/SKILL.md` for Vite worker setup.
2. `frontend/src/config.ts`: `FILE_NAME`, `LANGUAGE` mirrored from backend, with the "keep in sync" comment.
3. Layout: header (app name left, file name center, a static status placeholder right) and the editor filling the rest of the viewport.
4. Editor options: language from config, dark theme, `minimap` off, `automaticLayout` on, fonts readable.
5. Component split: `App.tsx`, `components/Header.tsx`, `components/Editor.tsx`.

## Files (expected)
`frontend/src/{App.tsx,config.ts,components/Header.tsx,components/Editor.tsx}` plus Vite config changes for Monaco workers if needed.

## Acceptance
- Typing in the editor works; TypeScript syntax highlighting is visible.
- Editor resizes with the window; no console errors or worker warnings.
- `typecheck`, `lint`, `test` pass.

## Verify
Open in a browser; type TS code; resize the window; check the console.

## Do NOT
Install Yjs, y-monaco, or the provider. Add any fetch/WebSocket code. Add a file tree.
