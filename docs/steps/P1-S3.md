# P1-S3 — Connect and sync

**Depends on:** P1-S2
**Goal:** Two browser tabs edit the same file and see each other live.

## Build
1. Install `yjs`, `@hocuspocus/provider`, `y-monaco` (frontend). Verify APIs per the grounding skill.
2. `frontend/src/collab/useCollab.ts`: a hook that creates one `Y.Doc` and one provider for `DOC_NAME`, exposes `{ ytext, provider, status }`, and destroys everything on unmount. Must be safe under React StrictMode (no double providers).
3. `Editor.tsx` binds Monaco to `ytext` with `y-monaco` after both editor and provider exist. Destroy the binding on unmount before the provider.
4. Do not set the editor value manually; the binding owns the text.
5. Read `VITE_WS_URL` from env.
6. Show the raw provider status string in the header placeholder (polished UX comes in P1-S7).

## Files (expected)
`frontend/src/collab/useCollab.ts`, `frontend/src/components/{Editor.tsx,Header.tsx}`, `frontend/src/config.ts`

## Acceptance
- Two tabs: typing in one appears in the other within a fraction of a second, both directions.
- Both tabs typing on the same line at once converge to identical text.
- Refreshing a tab keeps the shared text.
- No duplicated characters (check with StrictMode on, i.e. normal dev mode).

## Verify
Start backend and frontend; test with 2 tabs, including simultaneous typing and a refresh. Run all checks.

## Do NOT
Seeding, cursors/names, user cap, reconnect polish, status styling.

`P1-S3: live sync between clients`
