# P2-S3 — Switch files

**Depends on:** P2-S2
**Goal:** Clicking a file opens it; the editor rebinds to that file's doc.

## Build
1. `activeFileId` state in `App.tsx`, default `main`. Clicking a file in the sidebar sets it.
2. `useFileDoc(fileId)`: creates a provider for `file:<id>` (sharing the websocket), exposes `{ytext, provider, status}`, and destroys on id change or unmount. Only the active file has a live provider.
3. `Editor.tsx`: when `fileId` changes, destroy the old `MonacoBinding`, then bind to the new `ytext` and model. Set a Monaco language from the file extension (small map: ts, tsx, js, jsx, json, css, html, md; default plaintext).
4. Show the active file name in the header. Highlight the active file in the sidebar.
5. Awareness (name/color) also set on the file provider so remote cursors work in the open file.

## Files (expected)
`frontend/src/collab/useFileDoc.ts`, `frontend/src/components/{Editor.tsx,FileList.tsx,Header.tsx}`, `App.tsx`, `frontend/src/languages.ts`

## Acceptance
- Seed one more file manually through a test or temporary script (not in product UI) to verify switching; remove temporary code before commit.
- Switching files shows the right content with no flicker of the old file's text and no duplicated text.
- Two tabs on the same file sync; two tabs on different files don't interfere.
- Rapidly switching files 20 times leaves no console errors and only one active file provider (check via logs or devtools).

## Do NOT
Create/rename/delete UI, folders, presence-per-file indicators.
