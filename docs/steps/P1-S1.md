# P1-S1 — Backend host

**Depends on:** P1-S0
**Goal:** A Hocuspocus server that accepts clients on one document and syncs them. Proven by an automated test, not a browser.

## Build
1. Install `@hocuspocus/server` and `yjs` (backend deps), and `@hocuspocus/provider` (dev dep, for tests). Follow `.agents/skills/grounding/SKILL.md` first.
2. Extend `backend/src/config.ts`: `DOC_NAME = "file:main"`, `FILE_NAME = "main.ts"`, `LANGUAGE = "typescript"`, `TEXT_KEY = "content"`.
3. `backend/src/server.ts` exports `createServer({ port })` returning a started server and a `stop()` function (so tests can use random ports). `src/index.ts` calls it with config.
4. Accept only the document name `DOC_NAME`; reject any other.
5. Log connect and disconnect events (event, doc, short id). Never log content.
6. Serve `GET /health` → `{ "ok": true }` with CORS for `ALLOWED_ORIGIN`. Use whatever HTTP hook the installed Hocuspocus version provides; verify it.
7. Integration test: start server on a random port, connect two provider clients to `DOC_NAME`, make concurrent inserts at the same index from both, wait for sync, assert identical text. Also test: a client requesting another doc name is rejected.

## Files (expected)
`backend/src/{config.ts,server.ts,index.ts}`, `backend/src/server.test.ts`

## Acceptance
- `npm run dev` starts the server; `curl localhost:1234/health` returns `{"ok":true}`.
- Convergence test and rejected-doc-name test pass.
- Connect/disconnect logs appear, with no document content.

## Verify
Run backend checks. Start dev server, curl `/health`, stop the server cleanly.

## Do NOT
Seeding, user cap, presence, persistence, auth, frontend changes.

## Commit
`P1-S1: backend hocuspocus host with sync test`
